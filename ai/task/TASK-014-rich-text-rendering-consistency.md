# TASK-014 — Rich Text Rendering Consistency Audit & Implementation

## Executive Summary
Audit and implementation of rich text rendering consistency across the Unified Course Builder, Admin management pages, and Student/Public views in the Queens English Prestige platform.

---

## 1. Root Cause Analysis
- **Database Storage Format**: Rich text fields (`module_practices.description`, `final_exams.description`, `module_practice_questions.question`, `final_exam_questions.question`, `module_materials.content`, `course_levels.description`) are stored as **Option A: Raw HTML** generated by TinyMCE (e.g. `<p>asd</p>`, `<p>Practice Instructions:</p>`).
- **Cause of Visible Raw HTML Tags**:
  - In workspace views (`practice.blade.php`, `final-exam-section.blade.php`), standard Laravel Blade escaping `{{ $practice->description }}` was used, causing Blade to escape `<p>` to `&lt;p&gt;`, which rendered raw HTML text on screen.
  - On summary cards (e.g. `final-exam-folder.blade.php`), `$examSection->description` was output without stripping tags, causing `<p>asd</p>` to appear inside card previews.

---

## 2. Categorization & Security Boundaries

### Category A: FULL RICH CONTENT (Admin-Authored HTML)
- **Practice Workspace Instructions** (`practice.blade.php`): `{!! $practice->description !!}` inside `.rich-text-content`.
- **Final Exam Section Description / Instructions** (`final-exam-section.blade.php`): `{!! $exam->description !!}` inside `.rich-text-content`.
- **Question Detail / Preview**: `{!! $question->question !!}` inside `.rich-text-content`.
- **Module Material Content** (`module-material.blade.php`, `course-module-preview.blade.php`): `{!! $material->content !!}`.

### Category B: PLAIN TEXT SUMMARY (Cleaned & Truncated)
- **Final Exam Folder Card** (`final-exam-folder.blade.php`): `\App\Support\RichText::toPlainText($examSection->description, 120)`.
- **Question Cards** (`practice.blade.php`, `final-exam-section.blade.php`): `\App\Support\RichText::toPlainText($q->question, 120)`.
- **Level & Module Workspace Summaries** (`level.blade.php`, `module.blade.php`): `\App\Support\RichText::toPlainText(...)`.
- **Reorder Payloads**: `\App\Support\RichText::toPlainText($q->question, 60)`.

### Category C: FORM EDITOR VALUE
- Forms and drawers using TinyMCE (`textarea` with `js-admin-rich-text` / `x-model="drawerData.description"`). Works natively with raw HTML values.

### Category D: UNTRUSTED / USER-GENERATED CONTENT
- Student answers (`$answer->answer_text`), student names, review feedback: **Strictly escaped** using `{{ }}`.

---

## 3. Centralized Helper Class & Blade Components
Created centralized helper class `App\Support\RichText`:
- `RichText::toPlainText(?string $html, ?int $limit = null, string $end = '...')`:
  - Strips HTML tags cleanly.
  - Converts `<p>`, `<div>`, `<br>`, `<li>` tags to spaces to prevent word concatenation.
  - Decodes HTML entities (`&nbsp;`, `&amp;`, `&lt;`).
  - Normalizes multiple spaces/newlines.
  - Optionally limits length with `Str::limit`.

Created reusable Blade components:
- `<x-admin.rich-text :content="$content" />`
- `<x-admin.rich-text-summary :content="$content" :limit="120" />`
